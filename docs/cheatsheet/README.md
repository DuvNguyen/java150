# Java DSA Cheatsheet Directory

Thư mục tổng hợp cú pháp nhanh cho các chủ đề Cấu trúc dữ liệu & Giải thuật trong Java:

- [hashmap.md](file:///projects/java150/docs/cheatsheet/hashmap.md): Cú pháp `HashMap` (put, getOrDefault, putIfAbsent, keySet,...)
- [arraylist.md](file:///projects/java150/docs/cheatsheet/arraylist.md): Cú pháp `ArrayList` (add, remove, contains, sort,...)
- [arrays.md](file:///projects/java150/docs/cheatsheet/arrays.md): Thư viện tiện ích `Arrays` (toString, sort, equals, fill,...)
- [string.md](file:///projects/java150/docs/cheatsheet/string.md): Thao tác với `String` (charAt, toCharArray, substring, split,...)
- [stringbuilder.md](file:///projects/java150/docs/cheatsheet/stringbuilder.md): Cú pháp `StringBuilder` (append, charAt, deleteCharAt, reverse,...)
