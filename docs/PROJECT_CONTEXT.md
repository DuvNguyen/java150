# Bối cảnh & Mục tiêu học tập (Java DSA)

## Tổng quan
Dự án được khởi tạo làm không gian thực hành và học tập **Cấu trúc dữ liệu & Giải thuật (Java Data Structures and Algorithms)**.

## Các chủ đề trọng tâm
1. **Cấu trúc dữ liệu (Data Structures)**:
   - Mảng & Chuỗi (Arrays & Strings)
   - Danh sách liên kết (Linked Lists: Singly, Doubly, Circular)
   - Ngăn xếp & Hàng đợi (Stacks & Queues)
   - Cây (Trees: Binary Tree, BST, AVL, Trie, Heap)
   - Đồ thị (Graphs: Adjacency List/Matrix)
   - Bảng băm (Hash Tables / HashMap, HashSet)

2. **Giải thuật (Algorithms)**:
   - Sắp xếp & Tìm kiếm (Bubble, Insertion, Quick Sort, Merge Sort, Binary Search)
   - Đệ quy & Quay lui (Recursion & Backtracking)
   - Quy hoạch động (Dynamic Programming)
   - Thuật toán đồ thị (BFS, DFS, Dijkstra, Prim, Kruskal)
   - Thuật toán Tham ăn (Greedy Algorithms)

3. **Thiết kế hệ thống (System Design)**:
   - **Lý thuyết**: Load balancing, caching (Redis, CDN), message queue (Kafka, RabbitMQ), microservices vs monolith, API Gateway, rate limiting, database sharding/replication, consistency vs availability.
   - **Pattern**: Thiết kế theo bước: yêu cầu -> ước lượng scale -> high-level design -> deep dive từng thành phần -> trade-off.
   - **Câu hỏi mẫu**: "Thiết kế hệ thống rút gọn URL (TinyURL)", "Thiết kế hệ thống chat real-time", "Thiết kế newsfeed như Facebook".

4. **API & Giao tiếp giữa các service**:
   - **Lý thuyết**: REST vs GraphQL vs gRPC, HTTP methods/status code, idempotency, versioning, authentication (OAuth2, JWT), webhook.
   - **Câu hỏi mẫu**: "REST và SOAP khác gì nhau?", "JWT hoạt động thế nào, có nhược điểm gì?", "Idempotency key dùng để làm gì?".

5. **Kiến trúc phần mềm & Design Pattern**:
   - **Lý thuyết**: SOLID, DRY, KISS, các pattern: Singleton, Factory, Observer, Strategy, Repository, MVC/MVVM, Clean Architecture.
   - **Câu hỏi mẫu**: "Khi nào dùng Singleton, rủi ro của nó là gì?", "Giải thích Dependency Injection", "So sánh Monolithic và Microservices".

6. **Hệ điều hành & Mạng máy tính**:
   - **Lý thuyết**: Process vs Thread, deadlock, mutex/semaphore, TCP vs UDP, TCP handshake, DNS, HTTPS/TLS.
   - **Câu hỏi mẫu**: "TCP three-way handshake diễn ra thế nào?", "Deadlock là gì, cách phòng tránh?".

7. **Ngôn ngữ & Framework cụ thể (tùy stack công ty dùng)**:
   - **Ví dụ Java**: JVM, Garbage Collection, Spring Boot, Spring Security.
   - **Node.js**: Event loop, async/await, middleware.
   - **Python**: GIL, decorator, async framework (FastAPI/Django).

8. **Testing & DevOps cơ bản**:
   - Unit test, integration test, mocking, CI/CD pipeline, Docker, Kubernetes cơ bản, Git workflow.
